# Security policy

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/veritasvpn/VeritasVPN/security/advisories/new). Do not open a public issue for a vulnerability and do not include live credentials, account identifiers, access tokens, private keys, or exploit data in public channels.

Include the affected component and version, reproduction conditions, security impact, and any suggested mitigation. We will acknowledge a complete report as soon as practical, coordinate remediation privately, and publish a disclosure after affected users can update.

## Supported software

Security fixes target the current release of each platform that is listed as available on `veritasvpn.cloud/downloads.html`. Experimental builds and platforms labeled Coming soon are not production releases.

## Scope

The public website, account/API services, WireGuard provisioning and egress, protected DNS, supported clients, and release pipeline are in scope. Social engineering, denial-of-service traffic, automated scanning that degrades service, and accessing another user's data are prohibited.
