What a lawful order could reach
-------------------------------
If a valid order required it, the live systems could produce:

- an email address, if the account has one, and a password hash
- SHA-256 hashes of session, verification, and reset tokens
- device metadata (the Linux device model may be the hostname), tunnel
  IP, WireGuard public key, and last handshake time
- payment records in our database
- BTCPay invoices tagged with an account ID, on the self-hosted BTCPay
  server

We cannot produce browsing history, DNS query contents, traffic contents,
or a stored log of a user's real public IP at connect time. Redis
rate-limit keys that include a client IP, and a Cloudflare Turnstile IP
check, exist only for short windows (at most one hour for rate limits)
and are described in the Privacy Policy.
