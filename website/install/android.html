VeritasVPN for Android

Full-device WireGuard with private DNS threat protection, a clear live connection map, and the same private account you use across VeritasVPN.

Download Android APK

Install securely

  1. Download the signed APK

    Tap the download button above on your Android device.

  2. Allow this installation

    If Android asks, allow your browser to install apps from this source. You can turn the permission off again immediately afterward.

  3. Sign in and connect

    Open VeritasVPN, use your existing account, approve the Android VPN permission, and tap Connect now. DNS lookups go through the VeritasVPN protected gateway while the tunnel is up.

Kill switch: Always on — Android uses Always-on VPN and Block connections without VPN (no in-app off toggle). IPv6 is routed into the IPv4-only tunnel and blocked rather than allowed to bypass it.
