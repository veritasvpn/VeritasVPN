VeritasVPN for Linux

A WireGuard-only native build connected to the VeritasVPN node in Paraguay, with private DNS threat protection for malware and phishing domains.

Download Linux .deb

Install instructions

  1. Install (.deb)

    Double-click the .deb file or run: sudo dpkg -i veritasvpn-linux.deb

  2. Prefer a portable AppImage?

    Download the AppImage, then run chmod +x veritasvpn-linux.AppImage.

  3. Sign in & Connect

    Launch VeritasVPN, sign in with your account, and press Connect. Linux app requires sudo access to create and tear down the WireGuard tunnel. While connected, DNS uses the VeritasVPN protected gateway automatically.

Compatibility: Linux x86_64 (amd64) on Debian, Ubuntu, or any AppImage-compatible distribution.

Stealth mode

On restrictive networks that block or throttle plain WireGuard UDP, enable Settings → Stealth mode, then reconnect. Stealth wraps the tunnel in a TLS WebSocket so traffic looks more like ordinary HTTPS. Direct UDP remains the default when Stealth is off. This helps on harsh networks; it is not a claim of undetectability.

Kill switch

The Linux kill switch is always on while connected (no off option). It blocks non-VPN traffic at the firewall and routing layers if the tunnel drops, so your real IP and DNS do not leak over the clear connection. Connect requires nftables or iptables.
