VeritasVPN for Linux

A WireGuard-only native build connected to the VeritasVPN node in Paraguay, with Premium Veritas Shield toggles for malicious sites, trackers, ads, and adult sites. Blocking is DNS domain lists, not in-page removal.

Download Linux .deb

Install instructions

  1. Install (.deb)

    Double-click the .deb file or run: sudo dpkg -i veritasvpn-linux.deb

  2. Prefer a portable AppImage?

    Download the AppImage, then run chmod +x veritasvpn-linux.AppImage.

  3. Sign in & Connect

    Launch VeritasVPN and sign in. Tap the Veritas mark on Home to connect or disconnect. There is no separate Connect button. Linux asks for sudo to create and tear down the WireGuard tunnel. While connected, the kill switch stays on and DNS uses Veritas Shield. Premium filters for malicious sites, trackers, ads, and adult sites are under Settings → Veritas Shield. They block known domains in DNS. Ads or trackers loaded from the page itself can still run.

Compatibility: Linux x86_64 (amd64) on Debian, Ubuntu, or any AppImage-compatible distribution.

Stealth mode

On restrictive networks, open Settings → Stealth. Auto is the default: try UDP first, then Stealth if that handshake does not complete. UDP only never falls back. Stealth always starts with WireGuard inside TLS. Reconnect from Home to apply a change. This helps on harsh networks; it is not a claim of undetectability.

Kill switch

The Linux kill switch is always on while connected. There is no off switch in the app. It blocks non-VPN traffic at the firewall and routing layers if the tunnel drops, so your real IP and DNS do not leak over the clear connection. Connecting requires nftables or iptables. This is a full-device WireGuard tunnel. The Chrome extension is not yet available (coming soon). If you use one later, it only proxies the browser. How those differ.

Auto-reconnect

Auto-reconnect is always on (no off option). If the tunnel drops while you intended to stay connected, the app restores it automatically.
