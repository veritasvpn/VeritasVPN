VeritasVPN for macOS

A WireGuard-only Apple Silicon build connected to the VeritasVPN node in Paraguay.

Coming soon… View available platforms

Install the test build

  1. Download and open the DMG, then drag VeritasVPN into Applications.
  2. Open VeritasVPN, register or sign in, and press Connect.
  3. Approve the macOS administrator prompt so the app can configure the WireGuard tunnel.

Compatibility: macOS 12 or newer on Apple Silicon. This test build uses an ad-hoc integrity signature and is not yet Apple-notarized.
