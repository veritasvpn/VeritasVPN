Browser privacy

What does my browser reveal?

Even with a hidden IP, websites can still read many details from the browser itself. This is an educational snapshot, not a scare score.

What this checks

Local signals this browser exposes in JavaScript: language, timezone, screen size, platform, hardware hints, and similar fields sites often use for fingerprinting.

Why it matters

A VPN protects the network path; it does not make the browser anonymous. These signals can still help sites recognize a returning device. Use both network and browser defenses when privacy matters.
