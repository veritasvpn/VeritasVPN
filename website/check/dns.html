DNS leak test

Which DNS resolvers see your lookups?

Before a page loads, your device asks a DNS resolver for the site’s address. Whoever answers that query can learn which hostnames you visit.

What this checks

Which recursive DNS resolvers handle lookups for this browser session, using short-lived probe hostnames. Veritas does not store your query names.

Why it matters

HTTPS hides page content, not the names you resolve. ISP or third-party DNS can still build a browsing map. On VeritasVPN, Veritas Shield keeps resolution on the in-tunnel path instead.
