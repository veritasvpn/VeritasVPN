VPN leak test

Is this session leaking outside the tunnel?

A VPN only helps if traffic actually stays on the tunnel. This check looks for common ways browsers still expose a real-world address.

What this checks

Your public HTTPS IP, WebRTC ICE candidates (which can reveal local or public addresses), and whether an IPv6 path appears via a separate lookup.

Why it matters

If you expect only a VPN exit but WebRTC or IPv6 still shows another address, sites can identify you anyway. Run this before and after connecting to compare.
