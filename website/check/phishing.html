Link safety check

Does this link look suspicious?

Paste a URL to check for common phishing patterns before you open it. This tool does not visit the page, follow redirects, or run its code.

What it checks

HTTPS, deceptive brand names, Punycode, unusually long links, risky URL patterns, public DNS resolution, and the HTTPS certificate when available.

What it does not do

A result cannot prove a page is safe. New scams and compromised legitimate sites may not show these signals. Never enter a password or payment details just because a check looks clear.

Check a link

Only public HTTP and HTTPS URLs are accepted. Submitted links are not stored.
